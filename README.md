# 湖影に消えた花嫁

ブラウザで遊べるコマンド選択型ミステリーADVです。

## 公開方法（GitHub Pages）

1. このZIPを展開します。
2. 中のファイル・フォルダをすべてGitHubリポジトリ直下へアップロードします。
3. GitHubで **Settings → Pages** を開きます。
4. **Build and deployment** を  
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
   に設定します。
5. 保存すると、しばらくしてGitHub Pagesで公開されます。

## ファイル構成

- `index.html` … ゲーム本体
- `css/` … スタイル
- `js/` … ゲームデータ・進行処理
- `images/` … 背景・人物・証拠・タイトル画像
- `PROGRESSION_MAP_FINAL.md` … 第1章進行マップ
- `MOVEMENT_MAP_FINAL.md` … 移動マップ
- `.nojekyll` … GitHub Pages用

## 現在のゲーム仕様

- 第1章は「自動進行なし・移動主導型」
- 「次へ」ボタンは使用しない
- `はなす / きく / みる / しらべる / しょうこ / いどう`
- 情報を得ることで移動先が解放される
- 七条の心の声は使用しない
- 推理はプレイヤーが行う
- 背景画像スペースとコマンド欄を分離

## ローカル実行

`index.html` をダブルクリックしてブラウザで開いても動作します。


## 移動仕様修正
- 「いどう」は隣接地点だけでなく、**解放済みの全場所**を表示します。
- 一度解放された場所なら、ホテル・桐生屋・京都駅のどこからでも直接移動できます。
- 未解放の場所は表示されません。物語の進行条件は維持しています。
- 移動先は「ホテル」「桐生屋」「京都駅」に分けて表示します。


## UI調整
- コマンドは昔ながらの6個を右側に縦一列で表示
- 第1章開始時だけ、簡単な遊び方を表示
- その場で使えそうなコマンドを少し明るく表示
- 強調されていないコマンドも押せる。使えない場合はメッセージで案内
- 移動先は解放済みの場所だけ表示
- セーブ／設定はMENU内に集約


## 桐生兄弟の設定追加
- 桐生屋で宗次郎が初登場するとき「七条さんですね。兄から話は聞いています」と挨拶
- 桐生屋前の「きく」に「宗一郎について」を追加
- 七条「宗一郎さんに、顔がそっくりですね」
- 宗次郎「ははは、双子ですから」
- 終盤の宗一郎・宗次郎の相克につながる伏線として、序盤で双子設定を自然に提示


## 章OPメニュー残留修正
- 「第1章をはじめる」を押した瞬間に、章OPのHTMLメニューを消去
- 本編シーン描画時にも `choice-area` を初期化し、OPメニューが残らないよう二重対策

## セーブデータについて

- セーブデータは、**同じPC・同じブラウザ**でのみ利用できます。
- セーブデータはブラウザの **localStorage** に保存されます。
- **別のPC・別のブラウザ**には引き継がれません。
- **シークレットモード**では、終了時にセーブデータが消える場合があります。
- **ブラウザの閲覧データ・サイトデータを削除**すると、セーブデータも消える場合があります。
- 章をクリアした記録は、途中セーブとは別の `koeiBrideProgress_v1` に保存します。今後、第2章以降を追加した際の章選択に利用できます。
- 章クリア情報もブラウザの localStorage に保存するため、サイトデータを削除した場合は消えることがあります。

### ゲーム内での案内

- MENU → **ヘルプ** から、セーブについていつでも確認できます。
- 初めてセーブしたときだけ、保存場所とデータ消失条件について案内を表示します。


## GitHub軽量版について
- GitHubアップロード用に、使用中の画像だけを残しています。
- PNG画像はWebPへ変換し、見た目を保ちながら容量を削減しています。
- `index.html` からそのまま動作します。
- ZIPファイルそのものをGitHubへ置く必要はありません。ZIPを展開し、中身をリポジトリ直下へアップロードしてください。
