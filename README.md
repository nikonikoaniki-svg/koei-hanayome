# 湖影に消えた花嫁

ブラウザで遊べるコマンド選択型ミステリーADVです。

## 公開方法（GitHub Pages）

1. このZIPを展開します。
2. 中のファイル・フォルダをすべてGitHubリポジトリ直下へアップロードします。
3. GitHubで **Settings → Pages** を開きます。
4. **Build and deployment** を  
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
   に設定します。
5. 保存すると、しばらくしてGitHub Pagesで公開されます。

### GitHub向け軽量化

- 画面サイズ・画像の縦横比・コマンドやボタンの配置は完成版から変更していません。
- 画像は同じ縦横サイズのまま、GitHubで扱いやすいWebP形式へ軽量化しています。
- ZIPを展開し、フォルダの中身をそのままリポジトリ直下へアップロードしてください。

## ファイル構成

- `index.html` … ゲーム本体
- `css/` … スタイル
- `js/` … 第1章から第3章までのゲームデータと進行処理
- `images/` … 背景・人物・証拠・タイトル画像
- `PROGRESSION_MAP_FINAL.md` … 第1章進行マップ
- `MOVEMENT_MAP_FINAL.md` … 移動マップ
- `.nojekyll` … GitHub Pages用

## 現在のゲーム仕様

- タイトル画面の「章を選ぶ」から第1章・第2章・第3章を選択できます。
- 第2章は第1章クリア後、第3章は第2章クリア後に解放されます。
- 第1章は「自動進行なし・移動主導型」
- 第1章の終了画面から第2章「十八年前の警告」を開始できます。
- 第2章は、手掛かりを得ると移動先・人物・行動が順に解放されます。解放後は10地点を再訪できます。
- 第3章「港に残された影」は近江八幡駅・昼から始まります。駅で紗月の写真を見せ、八幡堀で久我の居住先を聞きます。久我の部屋では会話と質問を重ね、七条を信じた久我から鍵を預かります。通知の内容は表示されません。八幡堀・日牟礼八幡宮での再聞き込み後、夜の八幡公園駐車場で4つの痕跡を確認すると久我に2回電話しますが応答はありません。プレイヤー自身が近江八幡駅へ戻り、鍵で623番ロッカーを開けて4つの資料を読みます。資料をすべて確認すると彦根港が解放され、港の奥で久我清志の遺体を発見して章を終えます。
- 第2章で宗一郎への最終報告が終わると、第2章の終了画面を表示してクリアを記録します。そこから第3章を始めるか、タイトル画面の章選択から開始できます。
- タイトル画面の「章を選ぶ」からは、クリア記録がなくても第1章・第2章・第3章をそれぞれ冒頭から開始できます。単独開始のために設定される前章フラグは、前章のクリア記録として保存しません。
- 第3章では第1・2章と同じ7コマンド、localStorageセーブ、解放場所への再訪を使います。
- 移動先はプレイ中の章に限定され、第3章から第1・2章の場所へは移動できません。第3章の新規証拠は、小さな鍵、白いネイル飾り、久我のメモ、十八年前の新聞記事、操舵系統の点検記録、古い通帳の6点です。
- 桐生屋で宗次郎の許可を得ると紗月の部屋が解放されます。初回は交通メモ・断片メモ・しおり・陶器片が見つかります。大津港と図書館で事故と久我を確認し、部屋を再訪して断片メモを読み直した後に、神谷朔の連絡先を発見できます。
- 陶器片を調べると七条が信楽へ行く理由を口にし、信楽が解放されます。しおりまたは沙耶の話から石山寺を調べる理由が生まれます。
- 大津港で十八年前の事故を聞くと、図書館・郷土資料コーナーが解放されます。
- 神谷は初回訪問では調べものの内容を伏せ、事故記事を確認した後の再訪で紗月の依頼内容を話します。
- 久我の警告については、事故記事を読んだ後に大津港で証言を聞き、神谷の仕事場へ戻って文書コピーを得ます。
- 近江八幡の推理には、神谷から所在地を聞いた後、紗月の部屋で交通メモを読み直す必要があります。
- 2つの推理は条件がそろっただけでは始まらず、プレイヤーがホテルで「きく」を選んで開始します。
- 最終報告はホテルの宗一郎のところへ移動して行います。
- 第2章は `はなす / きく / みる / しらべる / みせる / いどう / しょうこ` の7コマンドです。
- 途中セーブの保存形式を維持し、第1章の既存セーブと証拠・フラグを引き継ぎます。
- 「次へ」ボタンは使用しない
- `はなす / きく / みる / しらべる / しょうこ / いどう`
- 情報を得ることで移動先が解放される
- 七条の心の声は使用しない
- 推理はプレイヤーが行う
- グラフィック上に切替式のコマンドパネルを表示

## ローカル実行

1. ZIPファイルを右クリックして、**「すべて展開」**を選びます。
2. GitHub Pagesへ公開するか、ローカルWebサーバー経由で `index.html` を開きます。

背景画像・外部スクリプトを読み込むため、ZIPを展開して `index.html`・`images`・`css`・`js` を同じ展開先に置いてください。ローカルでは `python3 -m http.server` などで起動できます。


## 移動仕様修正
- 「いどう」は隣接地点だけでなく、**解放済みの全場所**を表示します。
- 一度解放された場所なら、ホテル・桐生屋・京都駅のどこからでも直接移動できます。
- 桐生屋は「店先」「店内」の2地点に整理し、前撮り写真の確認も店内で行います。
- 桐生屋が解放された直後は「桐生屋前」だけが表示されます。宗次郎から双子の話を聞くと「桐生屋店内」へ移動できます。
- 桐生屋店内へ初めて入ったとき、そこで働く日野沙耶を紹介し、七条が沙耶の不審な動きを見逃さなかったことを明示します。
- 沙耶への「きく」では「さっき片付けたもの」を最初に表示します。沙耶はとぼけ、その後の質問にも歯切れの悪い答えを返します。
- 「しらべる」で机の上を確認すると紙の包みを発見し、さらに調べようとすると沙耶が棚の奥へ片付けます。
- 旧版のセーブデータ（K3・応接スペースを含む）は、読み込み時に店内へ自動変換します。
- 証拠に関わる対象を「見る」と、その場で対応画像が表示されます。
- ホテル外側の防犯カメラ映像は「きく」「みる」のどちらからでも同じ画像を確認でき、同じ進行条件が成立します。
- 行動後の会話は、最後の一文が表示し終わるとクリックせずにコマンド選択へ戻ります。最後の台詞と証拠画像は画面に残ります。
- 京都駅で必要な情報がそろっても、琵琶湖線方面という結論のメッセージは消えません。内容を確認してから「宗一郎に報告するためホテルへ戻る」を押すと先へ進みます。
- 宗一郎と会った後に専用の謎解き画面へ移り、中央に3問の選択肢が順番に表示されます。
- 全問正解後は「宗一郎との話を続ける」を押すと写真付き電報のパートへ進みます。最後の会話も自動では消えず、「第1章を終える」を押してから終了画面へ移ります。
- 未解放の場所は表示されません。物語の進行条件は維持しています。
- 移動先は「ホテル」「桐生屋」「京都駅」に分けて表示します。

## セーブデータの正式仕様

### 保存場所と利用条件

- セーブデータはブラウザの **localStorage** に保存されます。
- 原則として、保存に使った **同じPC・同じブラウザ**でのみ利用できます。別のPCや別のブラウザには自動で引き継がれません。
- **シークレットモード**では、ウィンドウを閉じた際にデータが消える場合があります。
- **ブラウザの閲覧データ・サイトデータを削除**すると、途中セーブと章クリア記録の両方が消える場合があります。

### 保存するデータ

| 種類 | 保存キー | 内容 |
| --- | --- | --- |
| 手動セーブ | `koeiBrideSave_moveDriven_v1` | 現在の場面、現在地、進行フラグ、取得済み証拠、行動履歴 |
| オートセーブ | `koeiBrideAutosave_v1` | 場面の区切りごとの進行状態。手動セーブとは別に保存 |
| バックアップ／保留 | 各セーブキーの `_backup`／`_pending` | 保存の更新前・更新途中からの復旧用 |
| 章クリア記録 | `koeiBrideProgress_v1` | クリア済みの章番号と初回クリア日時 |
| 設定 | `koeiBrideSettings_v1` | 文字音と文字送り速度 |
| 初回案内の確認状態 | `koeiBrideSaveNoticeSeen_v1` | 初回セーブ案内を表示済みかどうか |

### 章クリア記録

- 最後の会話を読み「第1章を終える」を押した時点で、第1章クリアを自動記録します。手動セーブを追加で行う必要はありません。
- 章クリア記録は手動セーブ・オートセーブとは別に保持します。「はじめから」を選んでも、既存セーブは削除しません。
- タイトルの「セーブデータを選ぶ」では、手動・自動セーブの章、場所、保存日時を確認して読み込めます。
- 保存データには形式バージョンと保存日時を記録します。更新時には旧形式を読み替え、元の手動セーブを残したまま新形式のオートセーブへ移行します。
- 保存は書き込み後に読み戻して確認します。更新前のデータはバックアップに残し、書き込み途中のデータも次回起動時に復旧候補として確認します。
- 第2章以降を追加した際に、章選択や次章解放の判定にそのまま利用できる形式です。
- 同じ章を再度クリアしても、最初に記録したクリア日時は上書きしません。

### 既存セーブとの互換性

- 既存の途中セーブキーは変更していません。
- 旧版のK3「応接スペース」は、読み込み時にK2「桐生屋店内」へ自動変換します。
- 旧セーブを読み込んだ時点で第1章クリア済みなら、章クリア記録へ自動反映します。
- 章クリア記録を追加しても、既存の進行フラグ・証拠・行動履歴は保持されます。

### ゲーム内での案内

- MENU → **ヘルプ** に、保存場所・利用条件・データが消える条件・章クリア記録について短く表示します。
- MENU → **設定** にも、保存先と章クリア記録についての短い案内を表示します。
- 初めて手動セーブしたときだけ、保存場所とデータ消失条件を案内します。2回目以降は通常の「セーブしました。」表示になります。
