# 湖影に消えた花嫁

ブラウザで遊べるコマンド選択型ミステリーADVです。

## 公開方法（GitHub Pages）

1. このZIPを展開します。
2. 中のファイル・フォルダをすべてGitHubリポジトリ直下へアップロードします。
3. GitHubで **Settings → Pages** を開きます。
4. **Build and deployment** を  
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
   に設定します。
5. 保存すると、しばらくしてGitHub Pagesで公開されます。

### GitHub向け軽量化

- 画面サイズ・画像の縦横比・コマンドやボタンの配置は完成版から変更していません。
- 画像は同じ縦横サイズのまま、GitHubで扱いやすいWebP形式へ軽量化しています。
- ZIPを展開し、フォルダの中身をそのままリポジトリ直下へアップロードしてください。

## ファイル構成

- `index.html` … ゲーム本体
- `css/` … スタイル
- `js/` … ゲームデータ・進行処理
- `images/` … 背景・人物・証拠・タイトル画像
- `PROGRESSION_MAP_FINAL.md` … 第1章進行マップ
- `MOVEMENT_MAP_FINAL.md` … 移動マップ
- `.nojekyll` … GitHub Pages用

## 現在のゲーム仕様

- 第1章は「自動進行なし・移動主導型」
- 「次へ」ボタンは使用しない
- `はなす / きく / みる / しらべる / しょうこ / いどう`
- 情報を得ることで移動先が解放される
- 七条の心の声は使用しない
- 推理はプレイヤーが行う
- グラフィック上に切替式のコマンドパネルを表示

## ローカル実行

1. ZIPファイルを右クリックして、**「すべて展開」**を選びます。
2. 展開後のフォルダにある `index.html` をダブルクリックします。

ZIPを展開せず、圧縮フォルダの中から `index.html` だけを直接開くと、背景画像を読み込めず黒画面になることがあります。`index.html`・`images`・`css`・`js`を同じ展開先に置いたまま起動してください。


## 移動仕様修正
- 「いどう」は隣接地点だけでなく、**解放済みの全場所**を表示します。
- 一度解放された場所なら、ホテル・桐生屋・京都駅のどこからでも直接移動できます。
- 桐生屋は「店先」「店内」の2地点に整理し、前撮り写真の確認も店内で行います。
- 桐生屋が解放された直後は「桐生屋前」だけが表示されます。宗次郎から双子の話を聞くと「桐生屋店内」へ移動できます。
- 桐生屋店内へ初めて入ったとき、そこで働く日野沙耶を紹介します。「しらべる」で机の上を確認すると紙の包みを発見し、さらに調べようとすると沙耶が棚の奥へ片付けます。
- 旧版のセーブデータ（K3・応接スペースを含む）は、読み込み時に店内へ自動変換します。
- 証拠に関わる対象を「見る」と、その場で対応画像が表示されます。
- ホテル外側の防犯カメラ映像は「きく」「みる」のどちらからでも同じ画像を確認でき、同じ進行条件が成立します。
- 行動後の会話は、最後の一文が表示し終わるとクリックせずにコマンド選択へ戻ります。最後の台詞と証拠画像は画面に残ります。
- 京都駅で必要な情報がそろっても、琵琶湖線方面という結論のメッセージは消えません。内容を確認してから「宗一郎に報告するためホテルへ戻る」を押すと先へ進みます。
- 宗一郎と会った後に専用の謎解き画面へ移り、中央に3問の選択肢が順番に表示されます。
- 全問正解後は「宗一郎との話を続ける」を押すと写真付き電報のパートへ進みます。最後の会話も自動では消えず、「第1章を終える」を押してから終了画面へ移ります。
- 未解放の場所は表示されません。物語の進行条件は維持しています。
- 移動先は「ホテル」「桐生屋」「京都駅」に分けて表示します。


## UI調整
- コマンドはグラフィック上の半透明パネルに2列×3段で表示
- コマンドを選ぶと6コマンドを一度隠し、同じパネル内を行動選択肢へ切り替え
- 行動開始時はパネルを隠し、最後のメッセージ表示後に自動で6コマンドへ戻る
- 行動選択肢には「コマンドに戻る」を表示
- PC・タブレット・スマホの縦横画面で共通の操作構成を使用
- 謎解き画面は通常の選択肢領域・コマンドパネルから完全に分離した専用レイヤーで表示
- 推理中は現在地・メッセージ・コマンドを隠し、選択肢を画面中央からはみ出さないよう表示
- 第1章開始時だけ、簡単な遊び方を表示
- その場で使えそうなコマンドを少し明るく表示
- 強調されていないコマンドも押せる。使えない場合はメッセージで案内
- 移動先は解放済みの場所だけ表示
- セーブ／設定はMENU内に集約

## セーブデータの正式仕様

### 保存場所と利用条件

- セーブデータはブラウザの **localStorage** に保存されます。
- 原則として、保存に使った **同じPC・同じブラウザ**でのみ利用できます。別のPCや別のブラウザには自動で引き継がれません。
- **シークレットモード**では、ウィンドウを閉じた際にデータが消える場合があります。
- **ブラウザの閲覧データ・サイトデータを削除**すると、途中セーブと章クリア記録の両方が消える場合があります。

### 保存するデータ

| 種類 | 保存キー | 内容 |
| --- | --- | --- |
| 途中セーブ | `koeiBrideSave_moveDriven_v1` | 現在の場面、現在地、進行フラグ、取得済み証拠、行動履歴 |
| 章クリア記録 | `koeiBrideProgress_v1` | クリア済みの章番号と初回クリア日時 |
| 設定 | `koeiBrideSettings_v1` | 文字音と文字送り速度 |
| 初回案内の確認状態 | `koeiBrideSaveNoticeSeen_v1` | 初回セーブ案内を表示済みかどうか |

### 章クリア記録

- 最後の会話を読み「第1章を終える」を押した時点で、第1章クリアを自動記録します。手動セーブを追加で行う必要はありません。
- 章クリア記録は途中セーブとは別に保持します。タイトル画面で「はじめから」を選び、途中セーブを削除しても章クリア記録は残ります。
- 第2章以降を追加した際に、章選択や次章解放の判定にそのまま利用できる形式です。
- 同じ章を再度クリアしても、最初に記録したクリア日時は上書きしません。

### 既存セーブとの互換性

- 既存の途中セーブキーは変更していません。
- 旧版のK3「応接スペース」は、読み込み時にK2「桐生屋店内」へ自動変換します。
- 旧セーブを読み込んだ時点で第1章クリア済みなら、章クリア記録へ自動反映します。
- 章クリア記録を追加しても、既存の進行フラグ・証拠・行動履歴は保持されます。

### ゲーム内での案内

- MENU → **ヘルプ** に、保存場所・利用条件・データが消える条件・章クリア記録について短く表示します。
- MENU → **設定** にも、保存先と章クリア記録についての短い案内を表示します。
- 初めて手動セーブしたときだけ、保存場所とデータ消失条件を案内します。2回目以降は通常の「セーブしました。」表示になります。
